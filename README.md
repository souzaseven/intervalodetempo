# 📅 Calculadora de Intervalo de Dias

Uma ferramenta web simples para calcular a diferença em dias entre duas datas, com design responsivo e animações fluidas.

<img src="https://github.com/souzaseven/intervalodetempo/blob/Desafios/intervaloexemplo.png?raw=true" width="60%" alt="Preview">

## ✨ Funcionalidades

- **Cálculo instantâneo** da diferença em dias
- **Validação automática** de datas
- **Design interativo** com:
  - Efeitos hover no container
  - Transição suave do resultado
  - Gradiente animado
- **Totalmente responsivo** para dispositivos móveis
- **Botão de limpar** conteúdo dinâmico

## 🛠 Tecnologias

- **Frontend**
  - HTML5 semântico
  - CSS3 com Flexbox e media queries
  - JavaScript puro (ES6)
- **Bibliotecas**
  - Font Awesome (ícones)
- **Analytics**
  - Google Analytics (GTAG)
  - Google AdSense

## 🚀 Como Usar

1. Acesse a calculadora online: [Link para deploy]
2. Selecione as datas nos campos:
   - Data Inicial
   - Data Final
3. O resultado aparecerá automaticamente
4. Use o botão "Limpar" para reiniciar
